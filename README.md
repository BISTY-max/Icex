# ICEX

Sitio web inicial del proyecto ICEX, creado con Next.js y listo para desplegar en Vercel.

## Desarrollo local

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Producción

```bash
npm run build
npm run start
```

En Vercel, importa este repositorio y conserva la configuración detectada de Next.js.
